# Input Svelte

Projeto de estudo com SvelteKit e Svelte 5 para desenvolver e experimentar componentes de entrada de dados.

## Stack
- Svelte 5
- SvelteKit 2
- Vite
- TypeScript

## Como executar

```bash
npm install
npm run dev
```

Para compilar, use `npm run build`; para visualizar o build, use `npm run preview`.
